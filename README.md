# PW Consulting | Cold Call Academy

Dieses Plugin ist das tägliche deutschsprachige Voice-Warm-up für Cold Calls mit Versicherungsagenturinhabern. Es trainiert Opener, Gesprächsführung, Einwandbehandlung, Terminierung und Nachqualifizierung auf Basis der von PW Consulting freigegebenen Trainingslogik.

## Installation auf einem Mac

```text
/Applications/ChatGPT.app/Contents/Resources/codex-cli/CodexCLI.app/Contents/MacOS/codex plugin marketplace add PKHRW/pw-cold-call-academy-plugin
```

```text
/Applications/ChatGPT.app/Contents/Resources/codex-cli/CodexCLI.app/Contents/MacOS/codex plugin add pw-consulting-cold-call-academy@pw-cold-call-academy
```

Anschließend die ChatGPT Desktop App vollständig schließen, neu öffnen und einen neuen Chat starten. Das Training kann mit `Start` oder direkt mit einem Schnellstart wie `Start – Level 2 – 3 Calls` begonnen werden. Für Voice anschließend den Sprachchat starten.

## Nutzung

- Level 1–4 oder Zufall
- 1, 3 oder 5 Calls pro Warm-up
- wechselnde realistische Versicherungsagenturinhaber
- während des Calls ausschließlich Kundenrolle
- Bewertung erst nach `Training beenden`
- kopierbare Zusammenfassung zur freiwilligen manuellen Weitergabe

## Datenschutz

Das Plugin hat keine externen Apps, Actions, Webhooks oder Datenbanken. Ergebnisse bleiben im jeweiligen Chat und werden nicht zentral überwacht oder automatisch an PW Consulting beziehungsweise Führungskräfte übertragen.

Die öffentliche Distribution enthält weder die interne Original-PDF noch die vollständige Playbook-Abschrift, echte Kunden- oder Mitarbeiterdaten oder Zugangsdaten.
